# Frozen contracts

The contract files define the data partitions, primary population, nested set family, loss, CRC selector, risk levels, outcomes and stop conditions. Frozen analysis identifiers are retained for evidence tracing.

- `data_contract.md`
- `experiment_contract.md`
- `analysis_contracts.md`
- `full_grid/run_contract.json`: saliency/occlusion across all 66 original predictor cells.
- `independent_reference/run_contract.json`: independent Liver source, exclusion, fitting, attribution and inference rules.
