# A-level aggregate results

This directory contains only structure-free macro-, family-, task-, target-, or diagnostic-level outputs needed to audit A1--A7 conclusions. Molecule-level rows, raw structures, SMILES, per-molecule predictions and attributions, checkpoints, logs, caches, and failed-run attempts are excluded.

The A7 subdirectory has a separate data-derived license notice because its summaries trace to ChEMBL v29 through MoleculeACE.
